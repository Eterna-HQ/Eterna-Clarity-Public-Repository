# Records Filing Guides

Use examples to choose where a record belongs. Start with the human guide; use the technical files only when you need them.

- [Household Records Filing Guide](open-household-records-taxonomy/START-HERE.md) and [workbook](open-household-records-taxonomy/taxonomy.xlsx).
- [Small Business Records Filing Guide](open-small-business-records-taxonomy/START-HERE.md) and [workbook](open-small-business-records-taxonomy/taxonomy.xlsx).

Each guide accompanies a fifteen-category reference with stable identifiers, JSON, CSV and a JSON Schema. The guide/workbook maintenance edition is 0.1.1. Category data remains at 0.1.0; no category IDs or meanings changed in this maintenance pass.

These are organizing references, not legal records-retention schedules. Keep required originals and use the systems your obligations require. Neither taxonomy has an open reuse licence yet. See its LICENSE-NOTICE.md before copying, adapting or redistributing it.
