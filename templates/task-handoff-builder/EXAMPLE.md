# Example: supplier delivery follow-up

This example is fictional.

## What needs to happen?

Confirm whether the replacement printer toner is arriving before Friday. If it is delayed, decide whether to pick up a local box instead.

## When does it need to happen?

Check by **Thursday at 2 p.m.** If there is still no delivery confirmation, call the supplier that afternoon.

## Who is taking it over?

Jordan.

## Where are the files or information?

- Order number and invoice: shared `Purchases / Office Supplies / September` folder.
- Supplier phone number: on the invoice.
- Delivery address: already confirmed on the order.

No password is needed for this task.

## What is the next step or decision?

Open the invoice and check the order status. If the delivery date is Friday or earlier, no action is needed. If the supplier cannot deliver by Friday, ask Priya whether to buy one box locally.

## What could block it, or when should they ask for help?

Do not approve a different toner model without asking Priya. If the supplier cannot find the order number, send Priya a message rather than placing a second order.

## Optional contact

Priya, office manager.

## Quick handoff check

Jordan should be able to answer:

- First step: open the invoice and check the delivery status.
- Missing information: none expected.
- Stop and ask for help if: the supplier proposes a different model, cannot find the order, or cannot deliver by Friday.

The example is intentionally short. A handoff is useful when it helps the next person act, not when it records every detail the original person knows.
