# Changelog

## 0.1.0 - 2026-08-25

**Status:** Public review candidate

Initial candidate includes:

- a five-question handoff model: who matters, what exists, where the real information lives, what is happening now, and what needs to keep happening;
- a browser-readable editable Markdown template;
- a formatted human workbook;
- separate spaces for the household handoff map, open loops, recurring responsibilities, protected-access arrangements, governing-document pointers, and handoff testing;
- an explicit natural-authority boundary so the plan points to governing records and systems instead of becoming a duplicate authority;
- an explicit legal-authority boundary: naming someone in the plan does not itself appoint them or change their authority;
- a security boundary against passwords, recovery codes, encryption keys, banking credentials, security answers, or other secrets;
- a deliberate scope boundary from the Family Emergency Document Checklist: first-hours emergency readiness stays there; days/weeks continuity and context live here;
- event-based and periodic review guidance.

### Paired-review refinement - 2026-08-25

- changed the five-question model from a requirement repeated in every household-area row to a model answered across the plan as a whole;
- made the Handoff Map an index and removed duplicate open-loop and recurring-responsibility fields;
- added a concrete first-pass path so useful continuity can be captured without completing the entire template;
- aligned the workbook with the Markdown by adding people-to-contact-first fields and governing-document/professional pointers;
- combined formal-authority pointers and protected-access arrangements into one human-facing **Authority & Access** workbook sheet;
- simplified public labels such as protected-access arrangements so they read naturally while preserving the security boundary;
- added an explicit reminder that the completed plan can still be sensitive even when it contains no passwords or recovery secrets;
- reinforced the one-detail-one-home rule to reduce stale duplicate information;
- validated the structure against a single-adult/renter household, a household with children/pets, a caregiver household, a household with no applicable formal legal documents, and a digitally dependent household.
