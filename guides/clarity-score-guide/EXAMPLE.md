# Fictional example

A fictional household has excellent organization for old receipts and warranties but cannot find the current insurance policy, has an outdated emergency contact and has never checked whether the backup copy can actually be opened.

A readiness score should not let the large amount of well-organized historical material hide those more important gaps. The detailed result should show the missing essentials and the next useful action.

This is an illustration of the public method. It is not a calculation for a real household or customer.
