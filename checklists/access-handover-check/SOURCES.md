# Sources and background

These sources informed the problem definition and boundaries of this resource. They do not endorse Eterna Clarity.

- Canadian Centre for Cyber Security — Implement access control and authorization  
  https://www.cyber.gc.ca/en/guidance/implement-access-control-and-authorization
- Canadian Centre for Cyber Security — Personnel security, including personnel termination  
  https://www.cyber.gc.ca/en/guidance/cyber-security-privacy-risk-management/itsp10033/personnel-security
- Innovation, Science and Economic Development Canada / CyberSecure Canada — Implement Access Control and Authorization: Fillable template and example  
  https://ised-isde.canada.ca/site/cybersecure-canada/en/certification-tools/implement-access-control-and-authorization-fillable-template-and-example

The guidance supports account lifecycle management, revoking access and authenticators when appropriate, retrieving organizational property, and retaining organizational access to information and systems. This Eterna Clarity checklist is an event-focused operational companion, not a replacement for an organization's access-control policy.
