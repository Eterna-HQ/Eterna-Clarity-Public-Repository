# Fictional example - Access handover

A fictional five-person service business is offboarding a contractor who managed the website and advertising.

| Area | Example answer |
| --- | --- |
| Business accounts identified | Done |
| Administrator ownership retained | Needs action - the advertising account has only one admin |
| Individual access changed | Not yet; scheduled for the final workday |
| MFA and recovery ownership retained | Not sure - domain registrar recovery phone must be checked |
| Files and information retained | Done - files are in the company shared drive |
| Devices and physical access handled | Does not apply |
| Shared access reviewed | Done through the company's password manager |
| Automations and integrations transferred | Needs action - website form automation runs under contractor identity |
| Vendor and service portals retained | Done |

**Proof task:** Another authorized staff member should sign in through their own account and publish a harmless website update or verify the advertising account without borrowing the contractor's identity.
