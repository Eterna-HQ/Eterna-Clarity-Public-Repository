# Sources and background

These sources informed the problem definition and boundaries of this resource. They do not endorse Eterna Clarity.

- Canadian Centre for Cyber Security - Tips for backing up your information (ITSAP.40.002)  
  https://www.cyber.gc.ca/en/guidance/tips-backing-your-information-itsap40002
- Canadian Centre for Cyber Security - Developing your IT recovery plan (ITSAP.40.004)  
  https://www.cyber.gc.ca/en/guidance/developing-your-it-recovery-plan-itsap40004
- Innovation, Science and Economic Development Canada / CyberSecure Canada - Backup and Encrypt Data: Fillable template and example  
  https://ised-isde.canada.ca/site/cybersecure-canada/en/certification-tools/backup-and-encrypt-data-fillable-template-and-example

The guidance supports defining what must be recovered, who is responsible, testing restoration regularly and using safe test approaches. This Eterna Clarity resource narrows that broader work to proving one real restore; it is not a full recovery plan.
