# Backup restore check

Use a **safe test location** when possible. Do not overwrite live information just to run this test.

## Test record

**What do you need to restore?**

**Backup source or service:**

**Restore point / version / date:**

**Safe test location:**

**Tested by (role is enough):**

**Test date:**

### Proof

- Did the restore complete? **Yes / No / Not sure**
- Could you open or read the restored information? **Yes / No / Not sure**
- What real task should this restored information support?
- Could you complete that task using the restored copy? **Yes / No / Not sure**
- What was missing, corrupted, outdated or confusing?
- What needs to change before you rely on this backup?

## Result

Treat the restore as **proven for this test only** when:

1. the restore completed;
2. the restored information opened correctly; and
3. the real task could be completed.

Anything else is a finding to fix or investigate.

Do not put passwords, recovery codes, encryption keys or other secrets in this check.
