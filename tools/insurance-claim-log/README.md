# Insurance Claim Log

Keep your claim number, insurer contact, conversations, damage notes, expenses and next actions in one timeline.

- [Use the browser tool](https://eternaclarity.com/resources/insurance-claim-log/)
- [Start with the blank CSV](CLAIM-LOG-TEMPLATE.csv)
- [See a fictional example](EXAMPLE.csv)
- [Review the sources](SOURCES.md)

The browser tool keeps the CSV rectangular by repeating the claim-level information on each log row. It can also save a small JSON data file so you can reopen your notes later.

Use your insurer's instructions and forms for the actual claim. This tool does not decide coverage or what evidence your insurer requires.
