# Home Inventory Builder

List significant belongings room by room, record optional serial numbers and values, and note where supporting photos or receipts are kept.

- [Use the browser tool](https://eternaclarity.com/resources/home-inventory/)
- [Start with the blank CSV](INVENTORY-TEMPLATE.csv)
- [See a fictional example](EXAMPLE.csv)
- [Review the sources](SOURCES.md)

The browser tool can export a CSV and a small JSON data file that can be opened again later. The value field is simply the amount **you choose to record**. It is not an insurance valuation or replacement-cost calculation.

Do not put unnecessary identity or account information into the inventory.
