# Account recovery check

For each important account, record only the non-secret recovery facts:

- **Account or service**
- **Why it matters**
- **Could you recover without your main phone?** Yes / No / Not sure
- **Is the recovery email or phone current?** Yes / No / Not sure
- **Is another recovery route available?** Yes / No / Not sure
- **What does recovery depend on?** A plain note such as `primary email`, `mobile carrier`, or `another admin`
- **Last checked**

Any **No** answer needs attention. Any **Not sure** answer should be tested through the provider's legitimate recovery settings or instructions before you rely on it.
