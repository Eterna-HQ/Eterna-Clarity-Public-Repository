# Account Recovery Check

Check how you would get back into important accounts if you lost your phone or usual sign-in method.

- [Use the browser check](https://eternaclarity.com/resources/account-recovery-check/)
- [Use the no-secrets checklist](CHECK.md)
- [See a fictional example](EXAMPLE.md)
- [Review the sources](SOURCES.md)

**Never put passwords, MFA codes, recovery codes, private keys or security answers in this resource.**

The tool records your answers. It does not attempt to sign in, test recovery with a provider, or guarantee that an account is recoverable.
